# 日历界面与展示截图国际化

## Why
默认英文 README 仍展示中文界面，用户无法确认英文可用性。需要真实的中英文界面与对应截图。

## What Changes
- 界面支持 English / 简体中文，默认跟随浏览器首选语言，其他语言回退英文。
- 顶部支持手动切换并在当前浏览器来源保存偏好；切换时保留日期、视图与筛选。
- 本地化日期、状态、详情、系统警告和复制指令，不翻译真实任务名称或正文。
- 用相同任务 ID 和周期的虚构中英文数据分别截图，更新两份 README。

## Impact
仅修改展示、静态资源路由、演示数据与文档，不改变任务调度或读写权限。不自动发布新版或修改现有安装。
