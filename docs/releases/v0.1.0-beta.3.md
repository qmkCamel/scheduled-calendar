# Scheduled Calendar 0.1.0-beta.3

给已有 Codex 本地定时任务补一个日历，无需迁移任务。这个社区预览版将中英文界面提供给通过 GitHub 安装的用户。

- 周、月和日程视图；搜索、状态筛选与任务详情。
- 界面跟随浏览器首选语言，也可手动切换 English / 简体中文；任务名称和正文保留原文。
- 完整插件、周期解析依赖与许可证随 ZIP 提供，无需 pip install 或模型 API key。
- 明确区分调度器记录的下一次运行与周期预估。

## 安装 / Install

要求 macOS、Python 3.11+ 和支持插件的 Codex。Requires macOS, Python 3.11+, and a plugin-capable Codex CLI/desktop app.

```sh
codex plugin marketplace add qmkCamel/scheduled-calendar --ref v0.1.0-beta.3
codex plugin add scheduled-calendar@scheduled-calendar-community
```

新建 Codex 任务，说“打开定时任务日历”。Start a new Codex task and ask “Open the scheduled calendar.”

也可以下载下方的 ZIP 和 SHA256SUMS，在下载目录校验后，进入解压得到的 `scheduled-calendar-0.1.0-beta.3/` 目录安装。Alternatively, download the ZIP and SHA256SUMS below, verify them, then install from the extracted `scheduled-calendar-0.1.0-beta.3/` directory:

```sh
shasum -a 256 -c SHA256SUMS
unzip scheduled-calendar-0.1.0-beta.3.zip
cd scheduled-calendar-0.1.0-beta.3
codex plugin marketplace add .
codex plugin add scheduled-calendar@scheduled-calendar-community
```

## English

A calendar for your existing local Codex automations. No task migration needed. This community preview brings the English and Simplified Chinese UI to GitHub installations, with week/month/agenda views, search, status filters, and task details. Recurrence dependencies and their licenses are bundled. No pip install or model API key is needed.

## 使用范围 / Preview scope

只读本机任务，在独立浏览器面板展示；不替换 Codex 原生页面。云端任务尚未接入，Windows/Linux 尚未验证。服务仅监听本机，关闭网页不会停止服务；需要时从插件目录运行 `python3 scripts/launch.py --stop`。内部存储格式可能随 Codex 更新而变化。

Read-only local tasks in a standalone browser panel. Cloud tasks are not connected; Windows/Linux are unverified. The loopback service continues after closing the page; run `python3 scripts/launch.py --stop` from the plugin directory when finished. Compatibility depends on Codex's internal storage.
