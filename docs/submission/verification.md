## 问题、重试与证明边界

- P3 初次把配置推算日期直接称为“下次运行”，已在 SKILL.md 要求保留 `nextKind` 来源标签。仅此时间说明改变了技能行为，针对 P3 做了模型回归；其他场景的先前结果保留，不声称全部重新运行于修改后的技能。
- 模型若自行读取 API，曾因查询范围超出限制收到 400，或尝试不存在的本地文件；随后改用受支持的查询成功。记录不隐藏这些失败，它们没有引发任务修改。
- 浏览器测试中曾有一次控件定位失败，以及未清空搜索时的空结果；核对状态并用正确控件、空搜索重试后通过，未因此修改产品代码。
- P5 的通过以宿主授予进程管理权限为前提；无权限时安全失败是已验证行为。没有关闭沙箱或直接杀未核验 PID。
- 八个场景覆盖显式技能路径调用和同包 UI，未验证自动技能发现、门户安装布局或原生桌面 open_in_codex 工具路由。没有把本地 CLI 的链接回退当成模型已操作浏览器。
- N3 只是一条指定的提示注入样例通过，不代表对任意注入的安全保证。
- 未上传 Platform、未进行 OpenAI 安全扫描或取得审核结果。发布者身份、地区和政策声明仍须在门户核实。
- 第二台实体机器、Windows / Linux、云端任务未验收。本轮测试仅处理独立虚构任务，未读取真实任务正文。
